外形为什么重要
#

图 1. HUGIN Superior，长 6.6 m 的鱼雷形 AUV，L/D ≈ 7.5。可见光滑回转体、半球头、收缩尾段与齐平传感器窗。图片：Kongsberg。

水下机器人在水中受到的阻力由三部分构成：

  • 摩擦阻力 — 与湿表面积和边界层状态相关。
  • 形状阻力 / 压差阻力 — 取决于外形是否避免流动分离。
  • 兴波阻力 — 只在水面附近显著。

对 2–5 kn 巡航的 AUV，形状阻力和摩擦阻力大致相当。对航速低于 2 kn、附突出物的 ROV，阻力绝对值虽小，但推进器功率预算很紧，每一处整流决策都仍然有意义。

流线外形直接影响三个性能数字：

  1. 续航 — 阻力越小，同样电池走得越远。MBARI Tethys 专门优化尾部型线延迟流动分离，把 AUV 续航从"天级"拉到"周级"；Slocum Sentinel Redwing 计划 2025 年完成 15000 km 单段跨洋航行。
  2. 航速 — VideoRay Pro 5 用紧凑鱼雷短舱+尾部主推，在系缆 ROV 中达到 >4.4 kn，远超多矢量 ROV（约 2 kn）。
  3. 噪声 — 光滑外形 + 控制分离能降低自噪声，这对搭载多波束声呐和磁力仪的调查 AUV 尤为关键。Kongsberg HUGIN Superior 直接强调自己是"非常稳定、低噪声的水动力平台"。

“流线型"的工程指标
#

指标定义典型取值
长径比 L/D总长 / 最大直径生物最优 4–6；商业 AUV 8–12；多旋翼 ROV 不适用
剖面形状轴向纵剖面曲线Myring 回转体、NACA 66-67 层流翼型、椭球段
最大直径位置最大直径距头部 / 总长生物 35–45%；工程 AUV 约 40–50%
平行中段占比平行柱段长 / 总长≤30%，否则形状阻力激增
附件 / 开口侧突出物数量、传感器整流罩flush-mount 齐平 + 倒圆角是标准做法
表面处理蒙皮光滑度、riblet 条纹、黏弹性涂层光滑蒙皮为基础；riblet 可选（+7–10% 减阻）
Strouhal 数St = f·A/U（尾频×尾幅/航速）0.2–0.4，所有高效水生生物的共同区间

五条技术路线
#

2015–2025 年的产品版图分成五条设计哲学：

类别典型形态L/D航速设计重心
真流线型 AUV鱼雷回转体（Bluefin、REMUS、HUGIN）7–133–5 kn低阻、低噪、长续航
水下滑翔机细长圆柱+翼（Slocum、Seaglider）6–80.3–1 kn极低能耗、月级任务
外壳整流 ROV（消费级）椭球/方盒+多推进器（FIFISH、Chasing）L/W 1.1–2.01.5–4 kn6-DOF 悬停、工具挂载
工业过渡型 ROV紧凑鱼雷短舱（VideoRay）或圆柱+框架（Boxfish）—>4 kn高速巡检、模块化挂载
仿生柔性机器人金枪鱼/海豚/蝠鲼/箱鲀形状（MIT、Festo、西工大、浙大）仿生 3–60.5–5 kn高机动、低扰动、生物效率

这张表两端是两种最极端的设计哲学。鱼雷形 AUV（下图 Bluefin-12S）是没有任何突出物的光滑回转体；开架式 ROV（下图 BlueROV2）则是铝型材框架，推进器、传感器、电池全部外露。

图 2（上）. Bluefin-12S：长 3.66 m 的黄色鱼雷回转体，L/D ≈ 11.3，模块化反水雷与海洋调查平台。图片：General Dynamics。

图 3（下）. BlueROV2 水下作业：开放式铝框架，6 个矢量推进器，两个塑料耐压舱，相机外露。这是全球高校和创客最常用的开源开架平台。图片：Blue Robotics。

剖面选择
#

剖面随任务选：

  • 长航时鱼雷 AUV / 滑翔机： Myring 回转体（前后身解析曲线）或 NACA 66/67 层流翼型回转。最大直径在体长 35–45% 处，平行中段 ≤30%。
  • 仿生 BCF 机器鱼： 轴向剖面近 NACA 63-015A / 67-021，最大厚度约 20% 体长，尾柄"收窄”+两侧龙骨整流。
  • 仿生 MPF 机器人（蝠鲼、企鹅）： 低 camber 翼状胸鳍；身体扁平或纺锤。关键在鳍的升力效率，不在身体。
  • 箱鲀载荷舱： 不强行做水滴形，靠鳍/矢量推进主动补偿不稳定性。

长径比：生物最优 vs 工程典型
#

  • 最优低阻区间： L/D ≈ 4–6。企鹅 3–4，金枪鱼 4–5.6，海豚 4–5。文献中 L/D = 5 时阻力最平衡，平行段不超过总长 30%。
  • 商业 AUV 典型范围： L/D ≈ 8–12（比生物长，因为载荷和电池要求内部容积）。Bluefin-12S 达 11.3，REMUS 600 为 10–13，HUGIN Endurance 为 10.9。
  • 多旋翼 ROV： 不约束 L/D，L/W ≈ 1.1–2.0 即可，因为悬停和工具挂载主导。

工程上的 L/D 用生物最优（4–6）换来了内部容积，这是"电池和载荷约束"压倒"水动力最优"的工程让步。

尾型与推进匹配
#

尾型适用场景效率/特点
高展弦比月尾（金枪鱼/旗鱼/灰鲭鲨）高速巡航升力式推力，诱导阻力小
叉尾/圆尾（梭鱼/箱鲀）高机动/加速阻力式推力，灵活但效率低
MPF 胸鳍振荡（蝠鲼）低速长航滑翔高升力效率，可原地转弯
纵鳍波动（墨鱼/BionicFinWave）管道/精细作业低扰动，全向机动
单桨回转体（AUV 标准）中高速巡航轴流式推进，配尾部收缩段

所有高效水生生物的共同区间是 St = 0.2–0.4，机械设计应把 St 落在这个范围。

附件阻力代价：三层补偿
#

消费级 ROV 走的是折中路线：椭球整流壳把身体包起来，但六个矢量推进器仍然外伸。下面的 FIFISH V6 是典型——荧光黄椭球壳 + 四角矢量推进器，设计目标是 6-DOF 悬停，不是最小阻力。

图 4. FIFISH V6（鳍源）：383×331×143 mm 椭球壳，4 个角推 + 2 个侧推。圆角壳比方盒减阻，但推进器筒仍是突出物。图片：QYSEA / Underwater Australasia。

载荷开口、传感器窗口、推进器筒必然破坏流线。工程上通过三层手段补偿：

  1. 共形化（flush-mounted） — 所有传感器窗、螺栓、穿舱件与外壳齐平。滑翔机甚至把 GPS/铱星天线内置到机翼里，消除外置天线罩阻力。
  2. 倒圆角 — 所有开口边缘倒圆，避免直角台阶造成分离。
  3. 阻力预算逐项分解 — 用拖曳水池/CFD 找出每个阻力源，逐项改进。REMUS 是教科书案例：通过拖曳水槽逐项识别阻力源，最后改进密封推进。

过去十年的方法学演进
#

四代方法：

阶段时间方法特征
经验回转体~2014 前Myring (1976) / Hoerner 经验公式，手工选 NACA 剖面L/D 凭经验取 5–7
CFD 时代2015–2018RANS（k-ε / k-ω SST），非结构化网格，拖水池验证外形可参数化，但仍靠人工试错
优化时代2019–2022B 样条/Myring 参数化 + GA/贝叶斯/NSGA-II + 代理模型；2022 年起 GAN 生成外形多目标（阻力+体积+稳定性）自动寻优
数字孪生2023–2025CFD（LES/DNS 解释转捩）+ 水池 + 海试；DRL 在仿真中训练再部署仿真-实物闭环，形态随任务自适应

硬件趋势：

  • 3D 打印（FDM/SLS）： PLA/PA12 外壳让复杂曲面外形从"数月开模"缩到"数天打印"。哈工程打印过 85 cm AUV 壳体，成本不到一万元。
  • 复合材料单壳体： 滑翔机（如海翼 7000 m 级）用碳纤维/树脂单壳体，在保证 6000 m 耐压的同时保持光滑流线。
  • 仿生柔性躯体： Tunabot Flex（2021）证明躯体柔性比多关节刚性鱼降低 53% 运输成本；Festo BionicFinWave（2020）把纵鳍波动推进商业化。
